# Torii — история версий

Версии по смыслу, а не по числу правок (semver): `МАЖОР.МИНОР.ПАТЧ`. До 1.0 были `0.x` (0.12.x уже лежала в Chrome Web Store как ранняя версия), `1.0.0` — первый полноценный релиз в магазинах.
Минор — заметный этап (новая большая возможность или пачка), патч — только починки, мажор — крупный перелом (несовместимые данные, полная переделка).
Версия живёт в `plitka/manifest.json` (её видно в панели настроек) и `package.json`.

## 1.0.0 — первый полноценный релиз: шесть языков, правый клик везде, закладки правятся с вкладки
- Цитата и «Слово дня» — только на русском (тексты не переводятся): на других языках её нет ни на вкладке, ни в меню «+ Виджет»; уже стоящая не теряется и возвращается вместе с русским (если её место заняли — встаёт на свободное).
- Новые языки интерфейса: испанский, немецкий, французский, португальский (к русскому и английскому). «Авто» берёт язык браузера; выбор — в «Ещё → Язык». Неделя в календарных виджетах — с понедельника у ru/es/de/fr, с воскресенья у en/pt; даты и числа — по языку; город погоды по умолчанию — по языку (Москва, Лондон, Мадрид, Берлин, Париж, Сан-Паулу), название города приходит на языке интерфейса. Название и описание в магазинах — на всех шести.
- Правый клик по любому блоку — его действия, а под чертой «Настроить» и «Удалить блок» (с «Вернуть»). По ссылкам: открыть, изменить, копировать адрес, удалить, добавить рядом; «Частые сайты» — «Скрыть этот сайт»; «Недавно закрытые» — восстановить (и все сразу); погода — обновить, сменить город, вид; часы — вид, 12/24 ч, секунды; поиск — поисковик, инкогнито, очистить недавние; дела и привычки — отметить, изменить, наверх, удалить; заметки — вставить дату, копировать, очистить; помодоро — старт, сброс, пропуск, 25/50 минут; отсчёт, курсы, цитата, слово дня; «Картинка» — сделать фоном вкладки. По фону вкладки — добавить виджет, изменить раскладку, настройки, следующий слайд, переключить раскладку. В полях ввода и в режиме редактирования — обычное меню браузера.
- Своя иконка у любой ссылки, закладки и частого сайта: картинка на всю плитку или сплошной цвет — со значком сайта поверх или без (галочка «Без значка — только цвет») (правый клик → «Своя иконка»); «Сбросить» в окне цвета возвращает иконку сайта. Общая для всех блоков с этим адресом, переносится в бэкапе.
- У «Ссылок» больше нет «+» в углу — добавление тоже по правому клику.
- Firefox: «Панель закладок» показывала «Меню закладок» (папку «Mozilla Firefox») вместо строки закладок — у Firefox своё дерево (строка — `toolbar_____`); разделители Firefox скрыты и не сбивают порядок при перетаскивании.
- «Панель закладок»: всё — по правому клику на плитке: открыть, изменить название и адрес, удалить (с «Вернуть»), а под чертой — добавить закладку или папку сразу за ней и «Все закладки»; по пустому месту — добавить в конец; перетаскивание — остальные расступаются на лету, брошенная на папку уходит внутрь. Это настоящие закладки браузера, без новых разрешений.
- Папки как в iOS: на значке — мини-иконки сайтов внутри, по клику — окошко поверх вкладки с плитками (3–5 в ряд по количеству), вложенные открываются там же со стрелкой «назад»; внутри тоже правый клик и перетаскивание.
- «Все закладки» — всё дерево закладок браузера в стиле Torii (пункт в меню по правому клику).
- Растягивание у края: блок, прижатый к краю сетки, при тяге ручки в сторону края растёт в обратную сторону (внизу — вверх, справа — влево, сверху — вниз, слева — вправо), а ведёшь обратно — сжимается и возвращается к краю.
- Часы: новый вид «Дуо» — часы жирно над минутами тонко (в настройках блока и по правому клику).
- Погода «Сейчас» по-новому, в строку: градусы, город и под ним «12° / 1°», справа значок погоды с подписью «Дождь». В блоке в одну клетку «макс / мин» и подпись не пропадают, подпись всегда под значком; пока обновляется — подписи нет, только кружок.
- Погода открывается сразу из памяти: смотрели меньше 3 часов назад — показывается как обычно и тихо обновляется; раньше (до суток) — серым переливается, как скелетон, вместо значка кружок загрузки, а внизу «5 ч назад», пока не придёт свежая (без сети — приглушена, «5 ч назад · нет сети»). «Обновить сейчас» в меню — тоже переливанием.
- Донат по языку: по-русски — Boosty, на английском — Tribute (Telegram); в панели, в карточке «Нравится Torii?» и на сайте. На GitHub — кнопка Sponsor с обеими ссылками.

## 0.12.4
- Лицензия — GPL-3.0 (до этого MIT): форки и изменённые версии должны оставаться открытыми.
- Поиск по умолчанию — «Как в браузере»: запрос уходит поисковику, выбранному в настройках браузера (Chrome Search API, разрешение `search`). Другие поисковики и префиксы остаются — по выбору. Требование Chrome Web Store: новая вкладка не должна подменять поисковик.

## 0.12.3
- Описание в магазине и подпись «Поиска» в меню виджетов — без перечисления брендов поисковиков (Chrome Web Store отклонил как «злоупотребление ключевыми словами»).

## 0.12.2

## 0.11.1
- Карточка для магазинов: описание на русском и английском, обоснования разрешений, политика конфиденциальности (`store/`).
- Скриншоты 1280×800 и промо-плитки на двух языках — `npm run store`.
- Название и краткое описание расширения переведены (`_locales`), в магазине на английском больше не будет русского названия.

## 0.11.0 — Firefox
- Сборка под магазины: `npm run build` → архивы для Chrome/Edge/Яндекса и для Firefox (свой манифест для addons.mozilla.org). Firefox-сборка проходит официальный валидатор Mozilla без ошибок.
- Смоук в движке Firefox (`npm run test:firefox`): все виджеты, редактор, раскладки, панель — без ошибок.
- Карточка «Разреши Torii приватные окна», если браузер не дал открыть поиск в инкогнито: в Chrome — кнопка в настройки расширения, в Firefox — подсказка, где включить; плюс «Открыть в обычной вкладке». Раньше в этом случае писалось «открыл в новой вкладке», но ничего не открывалось.
- Шрифты подключены форматом, который понимают все браузеры.
- Английский интерфейс: подсказка в «Заметках» теперь тоже переводится.

## 0.10.1

## 0.10.0 — раскладка целиком
- У каждой раскладки свои настройки: фон (меш или своя картинка), эффекты, стекло, шрифты, заголовок и иконка вкладки, слайд-шоу. Общие — только язык и имя.
- «+ Стандартная» — стандартные блоки и оформление по умолчанию; «+ Копия текущей» — копия всего.
- Резервная копия хранит настройки и картинку каждой раскладки.

## 0.9.2

## 0.9.1
- Погода в минимальном размере: «По часам» не прячет время, «Подробно» в низком блоке — в строку с показателями (а не как «Сейчас»).
- Ссылки в низком блоке — в один ряд, иконки ужимаются и остаются квадратными; «Список» и «Панель закладок» списком — по центру.
- Стрелочные часы в низком блоке: под циферблатом только дата, ничего не вылезает.
- Тест: вторая галерея — все виды виджетов в минимальном размере и проверка, что ничего не вылезает за блок.

## 0.9.0 — сохранённые раскладки
- Несколько раскладок (до 9): «Копия текущей» или «Стандартная», переименование, удаление; переключение из полосы редактора, из дока и по Alt+1…9 — на месте, без перезагрузки. Резервная копия сохраняет все.
- Погода: виды «Подробно» (ощущается, влажность, ветер, осадки, восход/закат) и «По часам».
- Привычки: календарная неделя — по-русски с понедельника; будущие дни не отмечаются.
- Выравнивание 3×3 у цитаты, слова дня и отсчёта.

## 0.8.0 — скорость

- Панель, миниатюры и меню виджетов собираются при первом открытии. Скрипт замеров `npm run perf`.
- Вкладка по умолчанию — «Torii» с иконкой-ториями. Меню виджетов — компактные монохромные макеты.
- Мелочи: заглушка и таймаут у «Картинки», значок загрузки у своей иконки вкладки, язык «Авто» без обрезки.
