# Torii — история версий

Версии по смыслу, а не по числу правок (semver): `0.МИНОР.ПАТЧ`, пока расширение не в сторе.
Минор — заметный этап (новая большая возможность или пачка), патч — только починки. `1.0.0` — первый релиз в Chrome Web Store.
Версия живёт в `plitka/manifest.json` (её видно в панели настроек) и `package.json`.

## 0.12.5
- Донат по языку: по-русски — Boosty, на английском — Tribute (Telegram); в панели, в карточке «Нравится Torii?» и на сайте. На GitHub — кнопка Sponsor с обеими ссылками.

## 0.12.4
- Лицензия — GPL-3.0 (до этого MIT): форки и изменённые версии должны оставаться открытыми.
- Поиск по умолчанию — «Как в браузере»: запрос уходит поисковику, выбранному в настройках браузера (Chrome Search API, разрешение `search`). Другие поисковики и префиксы остаются — по выбору. Требование Chrome Web Store: новая вкладка не должна подменять поисковик.

## 0.12.3
- Описание в магазине и подпись «Поиска» в меню виджетов — без перечисления брендов поисковиков (Chrome Web Store отклонил как «злоупотребление ключевыми словами»).

## 0.12.2
- Карточка «Нравится Torii?» — не чаще раза в день. Исправлено: в 0.12.0 она считалась «отвеченной» уже в момент показа и могла пропасть навсегда, даже если её не заметили.

## 0.12.1
- Карточка «Нравится Torii?» показывается с третьего открытия вкладки каждый раз, пока не нажмёшь «Не сейчас» или «Поддержать» — после этого больше никогда.
- В подвале панели настроек — ссылки на сайт и GitHub.

## 0.12.0 — поддержать автора
- В «Ещё» — раздел «Поддержать» со ссылкой на Boosty.
- Один раз за всё время, на третьем открытии вкладки, — ненавязчивая карточка «Нравится Torii?» с кнопками «Поддержать» и «Не сейчас»; больше не появляется.
- Сайт: кнопка Boosty рабочая, скриншоты открываются в галерее с пролистыванием.

## 0.11.1
- Карточка для магазинов: описание на русском и английском, обоснования разрешений, политика конфиденциальности (`store/`).
- Скриншоты 1280×800 и промо-плитки на двух языках — `npm run store`.
- Название и краткое описание расширения переведены (`_locales`), в магазине на английском больше не будет русского названия.

## 0.11.0 — Firefox
- Сборка под магазины: `npm run build` → архивы для Chrome/Edge/Яндекса и для Firefox (свой манифест для addons.mozilla.org). Firefox-сборка проходит официальный валидатор Mozilla без ошибок.
- Смоук в движке Firefox (`npm run test:firefox`): все виджеты, редактор, раскладки, панель — без ошибок.
- Карточка «Разреши Torii приватные окна», если браузер не дал открыть поиск в инкогнито: в Chrome — кнопка в настройки расширения, в Firefox — подсказка, где включить; плюс «Открыть в обычной вкладке». Раньше в этом случае писалось «открыл в новой вкладке», но ничего не открывалось.
- Шрифты подключены форматом, который понимают все браузеры.
- Английский интерфейс: подсказка в «Заметках» теперь тоже переводится.

## 0.10.1
- Подтверждение удаления заметное: крестик у раскладки разворачивается в красную плашку «Удалить?» с покачиванием; «Сбросить раскладку» — так же.

## 0.10.0 — раскладка целиком
- У каждой раскладки свои настройки: фон (меш или своя картинка), эффекты, стекло, шрифты, заголовок и иконка вкладки, слайд-шоу. Общие — только язык и имя.
- «+ Стандартная» — стандартные блоки и оформление по умолчанию; «+ Копия текущей» — копия всего.
- Резервная копия хранит настройки и картинку каждой раскладки.

## 0.9.2
- Ссылки «Списком»: подсветка при наведении облегает иконку с названием (а не тянется на всю колонку), иконка не подпрыгивает.

## 0.9.1
- Погода в минимальном размере: «По часам» не прячет время, «Подробно» в низком блоке — в строку с показателями (а не как «Сейчас»).
- Ссылки в низком блоке — в один ряд, иконки ужимаются и остаются квадратными; «Список» и «Панель закладок» списком — по центру.
- Стрелочные часы в низком блоке: под циферблатом только дата, ничего не вылезает.
- Тест: вторая галерея — все виды виджетов в минимальном размере и проверка, что ничего не вылезает за блок.

## 0.9.0 — сохранённые раскладки
- Несколько раскладок (до 9): «Копия текущей» или «Стандартная», переименование, удаление; переключение из полосы редактора, из дока и по Alt+1…9 — на месте, без перезагрузки. Резервная копия сохраняет все.
- Погода: виды «Подробно» (ощущается, влажность, ветер, осадки, восход/закат) и «По часам».
- Привычки: календарная неделя — по-русски с понедельника; будущие дни не отмечаются.
- Выравнивание 3×3 у цитаты, слова дня и отсчёта.

## 0.8.4
- Редактор: плашка блока («Поиск ⚙ ✕») висит над блоком, а не поверх содержимого; кнопки внутри поиска в редакторе приглушены.
- Ссылки: в блоке высотой в одну клетку подписи больше не пропадают — ужимается иконка (прячем подписи только ниже 52px).
- Недавние запросы: крестик в чипсе с одинаковыми отступами.

## 0.8.3
- Поиск: при наведении на строку иконка поисковика плавно чуть крупнее и ярче; логотип DuckDuckGo (утка в кольце) крупнее остальных, чтобы не казался мелким.

## 0.8.2
- «Свой» стиль блока хранит только отличия от общих настроек: тень, скопированная при выборе «Свой», больше не залипает после выключения общей тени.

## 0.8.1
- Вкладка: иконка Torii больше не берётся из старого кэша Chrome, пустое название — «Torii».
- Меню виджетов: помодоро и отсчёт без цифр, курсы без подписей валют, новые контурные погода и «недавно закрытые», проще цитата и слово дня.

## 0.8.0 — скорость
- Картинка-фон хранится отдельно: настройки весят ~1 КБ вместо мегабайт, ползунки не тормозят (шаг 15 мс → доли мс).
- Нет долгих задач при открытии вкладки: картинки раскодируются вне главного потока, карты жидкого стекла кэшируются.
- Панель, миниатюры и меню виджетов собираются при первом открытии. Скрипт замеров `npm run perf`.
- Вкладка по умолчанию — «Torii» с иконкой-ториями. Меню виджетов — компактные монохромные макеты.
- Мелочи: заглушка и таймаут у «Картинки», значок загрузки у своей иконки вкладки, язык «Авто» без обрезки.

## 0.7.0 — Torii
- Новое название и иконка (ворота-тории).
- Жидкое стекло без «засвета» на тёмном фоне, предпросмотр шрифтов при наведении, полка недавних запросов, новый фокус поиска.
- Приветствие отдельным блоком и декоративные шрифты, тени блоков, «свой стиль» подложки, мини-погода, макеты в меню виджетов.

## 0.6.0 — стекло и языки

- Панель заново («Ещё», свои приветствия, картинка во «Фоне»), языки ru/en.

## 0.2.0 — экраны

## 0.1.0 — первая версия
- Свободная сетка: блоки двигаются и растягиваются, часы, поиск, ссылки, заметки, погода.
