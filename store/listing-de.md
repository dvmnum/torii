## Detailed description (ausführliche Beschreibung, deutsche Fassung)

Torii macht deinen neuen Tab zu einem persönlichen Dashboard — angeordnet von dir, nicht von einer Vorlage.

FREIES LAYOUT
Was Torii von anderen Neuer-Tab-Seiten unterscheidet: Die Widgets stecken nicht in einer Spalte in der Mitte. Zieh sie an jede Stelle und ändere ihre Größe an jeder Ecke — das Raster hält alles sauber ausgerichtet. Layouts für breite Monitore und Laptops werden getrennt gespeichert.

WIDGETS
• Uhr — digital, Duo oder analog, mit Begrüßung und Datum
• Suche — mit der Standardsuchmaschine deines Browsers (oder einer anderen deiner Wahl), Präfixe für eine einmalige Suche woanders, ein Rechner direkt in der Suchleiste, Umschalt+Enter für die Inkognito-Suche
• Links und meistbesuchte Seiten — als Kacheln oder Liste, mit Website-Symbolen oder eigenem Bild bzw. eigener Farbe
• Lesezeichenleiste — deine Lesezeichen direkt im neuen Tab: bearbeiten, per Ziehen sortieren, Ordner öffnen sich wie bei iOS
• Wetter — jetzt, ausführlich, stündlich oder für die Woche
• Notizen, Aufgabenliste, wöchentlicher Gewohnheits-Tracker
• Pomodoro-Timer, Countdown zu einem Ereignis
• Bild (Katzen, Anime-GIFs oder dein eigenes), kürzlich geschlossene Tabs

LEBENDIGE HINTERGRÜNDE
Sanft animierte Verläufe mit 14 Vorlagen und einem Farbeditor. Oder dein eigenes Bild — wie es ist oder mit Effekt: Milchglas, Riffelglas, Raster, Duoton. Effekte darüber: Vignette, Leuchten, Partikel, Parallaxe mit dem Mauszeiger, ein Farbton passend zur Tageszeit. Eine Diashow aus deinen eigenen Hintergründen.

GLAS
Widgets aus Milchglas, die ihre Helligkeit an den Hintergrund anpassen, damit der Text lesbar bleibt. In Chrome gibt es außerdem „flüssiges Glas“ mit Lichtbrechung an den Rändern. Jedes Widget kann eigene Farbe, Schrift, Schatten und Unterlage haben.

RECHTSKLICK AUF ALLES
Jedes Widget hat sein eigenes Menü: einen Link bearbeiten, einen geschlossenen Tab wiederherstellen, die Stadt ändern, ein Bild als Hintergrund setzen. Rechtsklick auf freie Fläche, um ein Widget hinzuzufügen oder das Layout zu wechseln.

GESPEICHERTE LAYOUTS
Behalte mehrere Versionen deines neuen Tabs — „Arbeit“, „Zuhause“, „Lernen“ — und wechsle mit Alt+1…9. Jedes Layout hat eigene Widgets, eigenen Hintergrund und Stil.

SCHNELL UND PRIVAT
• Öffnet sofort; schwere Teile laden erst, wenn du sie brauchst
• Keine Werbung, keine Analyse, keine Datensammlung — alles bleibt in deinem Browser
• Sicherung in eine Datei, um alles auf einen anderen Computer mitzunehmen
• Zugriff auf Lesezeichen, meistbesuchte Seiten und letzte Tabs wird erst angefragt, wenn du so ein Widget hinzufügst
• Oberfläche auf Deutsch, Englisch, Russisch, Spanisch, Französisch und Portugiesisch
