# Torii — карточка в Chrome Web Store (русский)

Название и краткое описание магазин берёт из расширения (`plitka/_locales/ru/messages.json`):
- **Название:** Torii — новая вкладка
- **Краткое описание:** Новая вкладка со свободной раскладкой: двигай и растягивай виджеты как хочешь. Живые фоны, стекло, раскладки.

Скриншоты — `store/screenshots/ru/` (1280×800, в этом порядке), малая промо-плитка — `store/promo-440x280-ru.png`, большое рекламное изображение (1400×560) — `store/marquee-1400x560-ru.png`.
Пересобрать: `npm run store`.

## Подробное описание
(поле «Description» на вкладке «Store listing», русская версия)

Torii превращает новую вкладку в твою личную панель — и раскладываешь её ты, а не шаблон.

СВОБОДНАЯ РАСКЛАДКА
Главное отличие от других «новых вкладок»: блоки не стоят в одной колонке по центру. Перетаскивай их куда угодно и растягивай за углы до любого размера — сетка сама аккуратно выровняет. Для широкого монитора и ноутбука раскладки запоминаются отдельно.

ВИДЖЕТЫ
• Часы — цифровые или стрелочные, с приветствием и датой
• Поиск — 9 поисковиков и ИИ-ассистентов на выбор, быстрые префиксы для разового поиска в другом, калькулятор прямо в строке, поиск в инкогнито по Shift+Enter
• Ссылки и частые сайты — плитками или списком, с иконками сайтов
• Панель закладок — твоя строка закладок прямо на вкладке
• Погода — сейчас, подробно, по часам или на неделю
• Заметки, список дел, привычки на неделю
• Помодоро-таймер, обратный отсчёт до события
• Курсы ЦБ, цитата и слово дня, картинка (котики, аниме-гифки или своя)
• Недавно закрытые вкладки

ЖИВЫЕ ФОНЫ
Плавные анимированные градиенты, 14 готовых заготовок и свой редактор цветов. Или своя картинка — как есть или с эффектом: матовое стекло, рифлёнка, полутон, дуотон. Эффекты поверх: виньетка, свечение, частицы, «перспектива» за курсором, смена оттенка по времени суток. Слайд-шоу из своих фонов.

СТЕКЛО
Блоки из матового стекла, которое само подстраивает яркость под фон, чтобы текст читался. В Chrome — ещё и «жидкое стекло» с преломлением по краям. У каждого блока можно настроить цвет, шрифт, тень и подложку.

РАСКЛАДКИ
Сохрани несколько вариантов вкладки — «Работа», «Дом», «Учёба» — и переключайся одним нажатием Alt+1…9. У каждой раскладки свои блоки, фон и оформление.

БЫСТРО И ПРИВАТНО
• Вкладка открывается мгновенно, тяжёлые части грузятся только когда нужны
• Никакой рекламы, аналитики и сбора данных — всё хранится только в твоём браузере
• Резервная копия в файл — перенеси всё на другой компьютер
• Доступ к закладкам, частым сайтам и недавним вкладкам спрашивается, только когда добавляешь такой виджет
• Русский и английский интерфейс

## Вкладка «Privacy practices»

**Единственное назначение (Single purpose):**
Torii заменяет страницу новой вкладки настраиваемой панелью: виджеты (часы, поиск, ссылки, погода, заметки и др.), которые пользователь сам расставляет и оформляет.

**Обоснование разрешений:**
- `storage` — хранит настройки, виджеты и их расположение в браузере пользователя.
- `unlimitedStorage` — своя картинка-фон и картинки слайд-шоу весят мегабайты и не помещаются в стандартный лимит хранилища.
- `topSites` (необязательное) — виджет «Частые сайты» показывает сайты, которые пользователь посещает чаще всего. Запрашивается только при добавлении этого виджета.
- `sessions` (необязательное) — виджет «Недавно закрытые» показывает и восстанавливает недавно закрытые вкладки. Запрашивается только при добавлении этого виджета.
- `tabs` (необязательное) — нужно виджету «Недавно закрытые», чтобы показать адрес и заголовок закрытых вкладок (без него браузер отдаёт их пустыми). Запрашивается вместе с `sessions`.
- `bookmarks` (необязательное) — виджет «Панель закладок» показывает строку закладок пользователя; в «Ссылках» — разовый импорт из закладок. Запрашивается только при использовании.

**Удалённый код (Remote code):** Нет. Все скрипты, шрифты и библиотеки входят в пакет расширения.

**Использование данных (Data usage):** Chrome Web Store требует раскрывать и то, что обрабатывается только локально. Отметить:
- **Информация, позволяющая идентифицировать личность** — имя для приветствия (хранится только в браузере).
- **Данные о местоположении** — город для погоды (отправляется в Open-Meteo).
- **История веб-поиска** — частые сайты, недавно закрытые вкладки, закладки (показываются только на вкладке; адреса сайтов уходят в сервисы иконок).

Остальное — не отмечать. Подтвердить все три пункта о соблюдении политики: данные не продаются и не передаются, кроме как для работы самих функций.

**Политика конфиденциальности:** текст — `store/privacy-policy.md`; нужно разместить по публичной ссылке (например, GitHub Pages, gist или Telegraph) и указать URL.
