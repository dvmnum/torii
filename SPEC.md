# Plitka — ТЗ

## Идея
Новая вкладка для браузера уровня Bonjourr по красоте, но с **полностью свободной раскладкой**.
В Bonjourr всё прибито к центральной колонке. Здесь пользователь сам решает, где и какого размера каждый блок.

**Для кого:** люди, которые открывают новую вкладку по сто раз в день и хотят, чтобы она была красивой и полезной, а не пустой.
**Тон продукта:** стильно, спокойно, без мусора. Тёмная эстетика, стекло, живой фон.

## Что уже есть (v0.1 — прототип)
- MV3-расширение, подменяет новую вкладку.
- Сетка 24×12 на весь экран (gridstack.js). Режим редактирования: drag, resize за все углы и края, добавление и удаление блоков, отмена удаления.
- Виджеты: **часы** (формат, секунды, приветствие по имени, дата, выравнивание), **поиск** (Яндекс/Google/DDG/Bing, переключение по клику на иконку, ввод URL открывает сайт), **ссылки** (плитки/список/иконки, редактор списка), **заметки** (автосохранение), **погода** (Open-Meteo, город, кэш 30 мин).
- Любой виджет можно добавить несколько раз, у каждого свои настройки и переключатель стеклянной подложки.
- Контент масштабируется под размер блока (container queries).
- Настройки: 5 анимированных фонов, своя картинка с затемнением, размытие/плотность стекла, скругление, 6 акцентов, выключение анимации, экспорт/импорт JSON, сброс раскладки.
- Хоткеи: `E` — редактор, `/` — поиск, `Esc` — закрыть.
- Playwright-смоук-тест.

## Бэклог

### P0 — довести до ежедневного использования
1. **Проверка в реальном браузере с интернетом.** Иконки сайтов и погода проверены только с моками. Проверить в Chrome и Яндекс Браузере под Windows, поправить, что всплывёт.
2. **Разные экраны.** Раскладка сейчас одна. Нужно хранить раскладку отдельно под диапазоны ширины (например, <1280, 1280–1920, >1920). Если под текущий экран раскладки нет, взять ближайшую и масштабировать. Узкие окна (<700px): один столбец, блоки стопкой, редактор выключен.
   - *Готово, когда:* ноут 1366×768 и монитор 2560×1440 держат свои раскладки независимо, при ресайзе окна ничего не разъезжается и не перекрывается.
3. **Первый запуск.** Короткий онбординг: имя → выбор фона → подсказка «нажми E, чтобы двигать блоки». Показывать один раз.
4. **Пустое состояние и ошибки.** Погода без сети показывает аккуратную заглушку и повторяет попытку. Импорт кривого файла ничего не ломает.
5. **Производительность.** Первая отрисовка < 150 мс (без сети). Анимация фона не грузит CPU: блобы на `transform`, пауза при `document.hidden`.

### P1 — фичи
6. **Пресеты раскладок.** «Минимализм» (только часы + поиск), «Рабочий», «Дашборд». Плюс сохранение своих раскладок под именем и быстрое переключение из дока.
7. **Стиль на уровне блока.** Своя прозрачность и размытие, цвет подложки, скрыть заголовок, выравнивание контента. Слои: блоки могут перекрываться и иметь z-index («свободный режим» поверх сетки — обсудить).
8. **Новые виджеты:**
   - Помодоро (25/5, звук, прогресс-кольцо, счётчик за день)
   - Заметки 2.0: markdown-чекбоксы `- [ ]`, несколько заметок во вкладках
   - Цитата или слово дня
   - Мини-календарь
   - Курсы валют (ЦБ РФ, USD/EUR/CNY)
   - Картинка / GIF (свой файл в блоке)
   - Недавно закрытые вкладки (нужно разрешение `sessions` — спросить)
9. **Светлая тема** и авто-переключение по времени суток. Все цвета уже в CSS-переменных, вынести палитру светлой.
10. **Фоны:** фото дня (Unsplash, нужен ключ, или свой подобранный набор в репо), смена по времени суток, слайдшоу из своих картинок (IndexedDB вместо dataURL в storage).
11. **Синхронизация:** настройки и раскладка через `chrome.storage.sync` (без картинок, в пределах лимитов), картинки остаются локально.

### P2 — выпуск
12. Firefox-версия (AMO, бесплатно) и Opera Add-ons (оттуда же ставит Яндекс Браузер). Chrome Web Store — когда будет способ оплатить $5.
13. Локализация (ru/en) через `_locales`.
14. Страница политики конфиденциальности (данные не собираем), скриншоты и промо для сторов, скрипт упаковки в zip.
15. Финальное имя и иконка (Plitka — рабочее название).

## Нефункциональные требования
- Без сборки, ванильный JS, пока это не мешает. Если проект перерастёт — обсудить Vite + TS.
- Никакой телеметрии, никаких удалённых скриптов.
- Все внешние сервисы работают из России без VPN (Open-Meteo, Google s2 / Яндекс favicon — проверить на месте).
- Каждая фича — с обновлённым `tests/e2e.mjs` или новым тестом, скриншоты просматриваются глазами.
