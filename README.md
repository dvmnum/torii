# Plitka — новая вкладка со свободной раскладкой

Прототип v0.1. Chrome / Яндекс Браузер / Edge (Manifest V3).

## Как поставить
1. Открой `chrome://extensions` (в Яндексе — `browser://extensions`).
2. Включи «Режим разработчика».
3. «Загрузить распакованное» → выбери папку `plitka`.
4. Открой новую вкладку. Браузер может спросить, оставить ли изменения новой вкладки — оставь.

После правок в файлах жми ↻ у расширения на странице расширений.

## Управление
- **E** или карандаш справа внизу — режим редактирования: тащи блоки, тяни за углы и края.
- В редакторе при наведении на блок: ⚙ настройки блока, ✕ удалить (можно вернуть).
- **+ Виджет** — часы, поиск, ссылки, заметки, погода (одинаковых можно несколько).
- **/** — фокус в поиск, **Esc** — выйти/закрыть.
- Шестерёнка — фон, своя картинка, стекло, акцент, экспорт/импорт настроек.

## Структура
- `manifest.json` — манифест, подменяет новую вкладку
- `newtab.html` — страница
- `css/style.css` — весь дизайн
- `js/app.js` — сетка, редактор, настройки, модалки
- `js/widgets.js` — реестр виджетов (новый виджет = новый объект тут)
- `js/store.js` — хранилище (chrome.storage.local)
- `js/lib/gridstack-all.js` — gridstack.js 14 (MIT), drag & resize
- `fonts/` — Manrope (OFL)

Погода — Open-Meteo (без ключа), иконки сайтов — Google s2 → Яндекс → буква.
